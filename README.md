# 圆形印章生成器 MVP

这是第一版本地原型，针对“输入公司名称和印章用途，生成圆形印章”的需求制作。

## 使用

直接双击 `index.html`，或在 PowerShell 中运行：

```powershell
Start-Process .\index.html
```

当前版本支持：

- 上弧文字实时排版；
- 中心五角星和单外圆边框；
- 外圈细小随机断口，点击“换一组随机断口”可更换；当前页面修改文字和导出时保留同一组断口；
- 导出 SVG 矢量文件；
- 导出透明 PNG 印章图，外圈断口也保持透明；
- 生成 Photoshop JSX 脚本，在 Photoshop 中创建可编辑文字图层。

## 说明

生成的 SVG 是机器制作的矢量中间格式，正式交付前应根据厂家要求转换为 CDR、AI、PDF 或 DXF，并确认字体和尺寸要求。

Photoshop JSX 依赖客户电脑上的 Photoshop 和对应字体。上弧文字按单字建立文字图层，改字后建议通过本工具重新生成，以确保圆弧位置重新计算。
